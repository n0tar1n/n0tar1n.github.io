A.2 · Recover homographies

Eight unknowns, solved from manual matches.

For each source-to-reference pair, I clicked ten corresponding points in the same order. Setting h33 = 1 leaves eight unknowns, so the resulting 20 equations form an overdetermined system solved with least squares.

One correspondence: (x, y) → (u, v)

[x, y, 1, 0, 0, 0, −ux, −uy] h = u [0, 0, 0, x, y, 1, −vx, −vy] h = v

Stacking the pair of rows from every match produces Ah = b. The final homography maps homogeneous source coordinates to reference coordinates: p′ = Hp.

A.3 · Warp the images

Inverse warping, sampled two ways.

For every output pixel, I apply H−1 to locate the corresponding source coordinate. This inverse formulation avoids holes in the output. Nearest-neighbor uses the closest source pixel, while bilinear interpolation blends its four surrounding pixels for smoother edges.

Rectification 1 · Painted portrait

Rectification 2 · Card

Interpolation comparison. Nearest-neighbor is the simpler and faster sampler, but it makes diagonal edges appear blockier. Bilinear interpolation costs four source reads per sample and produces smoother transitions in both rectifications.

A.4 · Blend into mosaics

Feathered weighted averages.

I transform each image corner to determine a shared output canvas, warp every source image into it, and use an edge-distance weight mask as alpha. At every overlap pixel, the output is the normalized weighted average of the valid warped colors, rather than one image overwriting the other.

Limits of the model. The black regions are areas of the rectangular output canvas not covered by either warped photograph. Slight ghosting and perspective variation remain around close objects because a single planar homography cannot perfectly model scene depth or camera translation.

Takeaway

Good geometry begins with good correspondences.

Well-spread landmarks made the estimated transformations stable; inverse warping filled every destination sample; and feathered weights softened the seams that simple overwrite compositing would create.

Part B · Feature Matching for Autostitching

Replacing manual clicks with local features.

Part A supplied the geometry and compositing machinery. For Part B, I estimate the same source-to-reference transformations automatically: Harris corners propose candidate landmarks, ANMS spreads them across each image, normalized patches describe their appearance, Lowe-ratio matching proposes correspondences, and four-point RANSAC rejects outliers before the Part A warp-and-blend step.

Implementation. The full pipeline is implemented in autostitch.py; the supplied Harris helper is retained in harris.py. All three automatic results below use the same image pairs as Part A, so the manual and automatic mosaics can be compared directly.

B.1 · Harris corners + ANMS

Strong, well-spread candidate points.

I compute the single-scale Harris response (σ = 1), discard border points, and retain the 3,000 strongest candidates. Adaptive non-maximal suppression selects 500 spatially distributed corners: each point is scored by its distance to a sufficiently stronger neighbor (robustness factor 0.9), which avoids concentrating all features on one highly textured area.

B.2 · Feature descriptors

Blur, sample, and normalize the local appearance.

At every selected location, I blur the grayscale image (Gaussian σ = 1), sample an axis-aligned 40 × 40 neighborhood down to an 8 × 8 patch, flatten it, subtract its mean, and divide by its standard deviation. These bias/gain-normalized 64D vectors make matching less sensitive to local brightness and contrast changes.

B.3–B.4 · Match and robustly estimate H

Keep the consensus; reject the accidental look-alikes.

I compare every descriptor in image A with descriptors in image B using squared Euclidean distance. A match is accepted only when its nearest/second-nearest distance ratio is below 0.7. RANSAC then repeatedly fits a normalized-DLT homography from four random matches (3,000 trials), scores reprojection error with a 3-pixel threshold, and refits the winning consensus set.

B.4 · Manual vs. automatic stitching

Three panoramas, built two ways.

Each automatic homography feeds the same shared-canvas inverse warp and normalized average compositing used in Part A. The manual version depends on ten hand-clicked correspondences; the automatic version obtains its geometry entirely from the feature pipeline above.
