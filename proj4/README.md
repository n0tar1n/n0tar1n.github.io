# Submission folder

This is the self-contained project webpage and code hand-in folder.

## Files to submit

- `index.html`, `styles.css`, and the complete `assets/` folder as the project webpage.
- A PDF of the webpage: open `index.html` in a browser, then use **Print → Save as PDF**.
- The complete `code/` folder as the code submission.

Before exporting the final PDF:

1. Replace `[Your Name]` in `index.html`.
2. Crop the black unused canvas regions from the three mosaic presentation images, then replace the matching files in `assets/`.
3. Open `index.html` locally and verify every image loads.
